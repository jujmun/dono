Each directory is a point-in-time legal suite. Historical suites are retained as
evidence and must not be edited as if they govern the beta.

| [`v3.0/`](v3.0/) | 3.0 | Current, content-ready source; display-ready HTML/PDF artifacts not yet rendered |

| [`v2.0/`](v2.0/) | 2.0 | Historical second public suite |

| [`legacy-unversioned/`](legacy-unversioned/) | Mixed | Loose historical files of uncertain provenance |

links therefore reflect the repository layout that existed when those versions
were created; follow the current [`../../engineering/legal-launch/README.md`](../../engineering/legal-launch/README.md)
